# Smart Factory IoT Monitoring System

IoT-based Smart Factory Monitoring System developed using Arduino, MQTT, and ThingsBoard for real-time industrial monitoring, automation, and remote control.

---

## 📌 Overview

This project simulates a smart industrial environment where multiple sensor nodes monitor factory conditions and communicate through IoT protocols for centralized monitoring and control.

The system collects real-time sensor data, transmits it using MQTT, and visualizes the data on the ThingsBoard dashboard for remote access and automation.

---

## 🚀 Features

- Real-time factory monitoring
- Multi-node IoT communication
- MQTT-based data transmission
- ThingsBoard dashboard integration
- Remote monitoring and control
- Sensor data visualization
- Industrial automation support

---

## 🛠 Technologies Used

- Arduino / ESP Modules
- Embedded C++
- MQTT Protocol
- ThingsBoard IoT Platform
- Sensors and Actuators
- IoT Communication
